# Idea

A communication device that can be used in locations where there is no internet that can be used in emergencies.


Makes use of LoRa to connect to another device of the same type, allowing them to communicate with each other.

The device will have a compass that always makes the devices point towards one another, allowing both users to always be able to find each other when either is lost.

The device will have a way of sending short messages to one another.

The device should have a small speaker and gyroscope to allow the device to detect if the user has fallen over and cannot get up/is unresponsive. When the device detects that it's laying on it's side for a certain amount of time it will first continuously send an audible alert to the user to give them time to set the device upright. If the user does not respond the device will send an alert to the other device, notifying that the user is unresponsive.
